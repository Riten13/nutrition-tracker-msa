# Meal Planning Microservice — Project Flow

## System Overview

```
Client (Postman / Frontend)
        │
        ▼
Meal Planning Service  ──────────►  Food Database Service
   (port 3001)          OpenFeign        (port 3000)
        │
        ▼
  MongoDB Atlas
  (food_database)
```

This service has **two data sources**:
1. **MongoDB Atlas** — stores meal plans and meals (persistent)
2. **Food Database Service** — provides nutrition data (fetched on-demand, never stored)

## Request Flows (Step by Step)

### Flow 1 — Create Meal Plan

```
POST /api/meal-plans
        │
        ▼
MealPlanController.createMealPlan(request)
        │
        ▼
MealPlanService.createMealPlan(request)
   │  Build MealPlan entity
   │  Set createdAt = now()
        │
        ▼
MealPlanRepository.save(mealPlan)
        │
        ▼
MongoDB Atlas → meal_plans collection
        │
        ▼
Return MealPlanResponse (201 Created)
```

---

### Flow 2 — Get User's Meal Plan

```
GET /api/meal-plans/{userId}
        │
        ▼
MealPlanController.getMealPlan(userId)
        │
        ▼
MealPlanService.getMealPlanByUserId(userId)
   │  MealPlanRepository.findByUserId(userId)
   │  MealRepository.findByMealPlanId(planId)
        │
        ▼
Return MealPlanResponse with nested List<MealResponse> (200 OK)
```

---

### Flow 3 — Add Meal ⭐ (OpenFeign call)

```
POST /api/meal-plans/{planId}/meals
        │
        ▼
MealPlanController.addMeal(planId, request)
        │
        ▼
MealPlanService.addMeal(planId, request)
   │
   ├── [1] MealPlanRepository.findById(planId)
   │         └── throws 404 if not found
   │
   ├── [2] FoodServiceClient.getFoodById(request.foodId)
   │         └── GET http://localhost:3000/api/foods/{foodId}
   │         └── throws error if food not found
   │
   ├── [3] Build Meal entity
   │         { mealPlanId, foodId, mealType, quantity }
   │         ← NO nutrition data stored
   │
   └── [4] MealRepository.save(meal)
              └── MongoDB Atlas → meals collection
        │
        ▼
Return MealResponse (201 Created)
```

---

### Flow 4 — Get All Meals

```
GET /api/meal-plans/{planId}/meals
        │
        ▼
MealPlanService.getMeals(planId)
   │  MealPlanRepository.findById(planId)  → 404 if missing
   │  MealRepository.findByMealPlanId(planId)
        │
        ▼
Return List<MealResponse> (200 OK)
```

---

### Flow 5 — Delete Meal

```
DELETE /api/meal-plans/{planId}/meals/{mealId}
        │
        ▼
MealPlanService.deleteMeal(planId, mealId)
   │  MealPlanRepository.findById(planId)  → 404 if missing
   │  MealRepository.findById(mealId)      → 404 if missing
   │  MealRepository.delete(meal)
        │
        ▼
Return 204 No Content
```

---

### Flow 6 — Daily Summary ⭐ (Multiple OpenFeign calls)

```
GET /api/meal-plans/{userId}/daily-summary
        │
        ▼
MealPlanService.getDailySummary(userId)
   │
   ├── [1] MealPlanRepository.findByUserId(userId) → 404 if missing
   │
   ├── [2] MealRepository.findByMealPlanId(planId)
   │         └── Returns all meals for this plan
   │
   └── [3] For EACH meal:
             FoodServiceClient.getFoodById(meal.foodId)
             └── GET http://localhost:3000/api/foods/{foodId}
             
             factor = meal.quantity / 100.0
             
             totalCalories += food.nutrition.calories * factor
             totalProtein  += food.nutrition.protein  * factor
             totalCarbs    += food.nutrition.carbohydrates * factor
             totalFat      += food.nutrition.fat       * factor
        │
        ▼
Return DailySummaryResponse (200 OK)
  { date, totalCalories, totalProtein, totalCarbs, totalFat }
```

## Database Design

### Collection: `meal_plans`

```
{
  "_id":       ObjectId("64abc123..."),   ← auto-generated by MongoDB
  "userId":    1,
  "planDate":  "2026-09-03",
  "createdAt": "2026-09-03T10:00:00"
}
```

### Collection: `meals`

```
{
  "_id":        ObjectId("64xyz789..."),  ← auto-generated by MongoDB
  "mealPlanId": "64abc123...",           ← reference to meal_plans._id
  "foodId":     "123",                   ← reference to Food Database Service
  "mealType":   "BREAKFAST",
  "quantity":   200.0
}
```

### Relationship

```
meal_plans (1) ────────────── (*) meals
    _id              mealPlanId (foreign key)
```

One `MealPlan` → many `Meals` linked by `mealPlanId`.

## OpenFeign Communication

```java
@FeignClient(name = "food-service", url = "${food-service.url}")
public interface FoodServiceClient {
    @GetMapping("/api/foods/{foodId}")
    FoodDto getFoodById(@PathVariable("foodId") String foodId);
}
```

- Spring Cloud generates the HTTP implementation at startup.
- Base URL read from `application.yml` → `food-service.url: http://localhost:3000`.
- Returns `FoodDto` which contains a nested `NutritionDto`.
- If the Food Database Service is down, Feign throws a `FeignException`.

## What Gets Stored vs. Fetched

| Data | Stored in MongoDB? | Source |
|------|--------------------|--------|
| Meal plan info | ✅ Yes | Created by client |
| foodId | ✅ Yes (as String) | Sent by client |
| mealType | ✅ Yes | Sent by client |
| quantity | ✅ Yes | Sent by client |
| Food name | ❌ No | Fetched from Food DB Service |
| Calories | ❌ No | Fetched from Food DB Service |
| Protein | ❌ No | Fetched from Food DB Service |
| Carbohydrates | ❌ No | Fetched from Food DB Service |
| Fat | ❌ No | Fetched from Food DB Service |
